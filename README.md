# Номенклатура ночи — читалка маньхуа

Удобная адаптивная читалка без фреймворков: вертикальная прокрутка без внутренних скролл-контейнеров, поддержка Android, запоминание прогресса, тёмная и светлая темы, настройка промежутков, навигация по главам.

## Запуск

Статическая страница `index.html`. Для локального теста используйте `python -m http.server 8000`, затем откройте `http://localhost:8000`. На GitHub: **Settings → Pages → Build and deployment → Source: GitHub Actions**. После деплоя сайт будет доступен по адресу `https://warfwar.github.io/Manhwa/`.

## Где изображения

`data/catalog.json` хранит порядок глав и страницы. Изображения размещаются в `chapters/01/01.webp`, `chapters/01/02.webp` и т. д. Если изображений в репозитории нет, глава показывается как ожидающая загрузки. Сайт поддерживает **локальный импорт ZIP и CBZ** (изображения автоматически сохраняются в IndexedDB браузера), так что можно читать свои готовые выпуски с телефона, не разворачивая сервер. Архивы сохраняются только на устройстве; между браузерами они не синхронизируются.

Подготовить локальный пакет с изображениями из архивов главы можно скриптом `scripts/build_catalog.py`, размещающим рисунки и создающим `catalog.json`. Готовые изображения не следует маркировать как завершённые, если они всё ещё содержат повторяющиеся/ошибочные кадры.

## Статус иллюстрированных глав

- Глава 1 — собрана, 9 вертикальных фрагментов.
- Глава 2 — собрана иллюстрированная версия, может требовать дополнительной редакторской проверки.
- Глава 3 — раскадровка; не считать чистовой маньхуа.
- Глава 4 — иллюстрированная адаптация, 4 страницы.
- Глава 5 — 7 страниц, визуальная доработка продолжается.
